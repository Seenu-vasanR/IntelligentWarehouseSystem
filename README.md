## 📌 Project Overview

The **Intelligent Warehouse & Inventory Management System** is a web-based application developed using Python and Django to manage warehouse products, categories, suppliers, and stock movements.

It helps users monitor inventory levels, manage stock in and stock out operations, and identify low-stock and out-of-stock products efficiently.

## ✨ Key Features

- 📊 **Dashboard:** View total products, categories, suppliers, and stock quantity.
- 📦 **Product Management:** Add, update, search, and manage products.
- 🗂️ **Category Management:** Organize products by category.
- 🚚 **Supplier Management:** Maintain supplier information.
- 📥 **Stock In:** Update inventory when new stock arrives.
- 📤 **Stock Out:** Reduce inventory when products are issued.
- ⚠️ **Low Stock Alert:** Identify products with low stock.
- 🔴 **Out of Stock Alert:** Identify unavailable products.
- 🔍 **Search & Filters:** Find products and filter stock movements.
- 🔐 **Admin Panel:** Manage warehouse data through Django administration.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/Seenu-vasanR/IntelligentWarehouseSystem.git
```

**2. Navigate to the project folder**

```bash
cd IntelligentWarehouseSystem
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install Django PyMySQL python-dotenv
```

**6. Configure MySQL**

Create a MySQL database named `intelligent_warehouse` and configure your database credentials in a local `.env` file.

**7. Apply migrations**

```bash
python manage.py migrate
```

**8. Run the development server**

```bash
python manage.py runserver
```

Open your browser:

```text
http://127.0.0.1:8000/
```
