## 🟣 About The Project

The **Intelligent Warehouse & Inventory Management System** is a web-based application developed using Python and Django to simplify warehouse operations and inventory tracking.

The application enables users to manage products, categories, suppliers, and stock movements while monitoring inventory levels. It also provides stock status information to help identify low-stock and out-of-stock products.

## 🔵 Key Features

- 📊 **Dashboard:** Displays total products, categories, suppliers, and available stock.
- 📦 **Product Management:** Manage product details, prices, quantities, and categories.
- 🗂️ **Category Management:** Organize products into different categories.
- 🚚 **Supplier Management:** Maintain supplier contact and company information.
- 📥 **Stock In Management:** Record incoming stock and update inventory quantities.
- 📤 **Stock Out Management:** Record outgoing stock and maintain accurate quantities.
- ⚠️ **Stock Monitoring:** Identify in-stock, low-stock, and out-of-stock products.
- 🔍 **Search and Filtering:** Search products and filter stock movement records.
- 🔐 **Admin Panel:** Manage application data through Django Administration.

## 🟡 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/Seenu-vasanR/IntelligentWarehouseSystem.git
```

**2. Navigate to the project directory**

```bash
cd IntelligentWarehouseSystem
```

**3. Create and activate a virtual environment**

```bash
python -m venv venv
venv\Scripts\activate
```

**4. Install dependencies**

```bash
pip install Django PyMySQL python-dotenv
```

**5. Configure MySQL**

Create a MySQL database named `intelligent_warehouse` and configure your database credentials in a local `.env` file.

**6. Apply migrations**

```bash
python manage.py migrate
```

**7. Run the development server**

```bash
python manage.py runserver
```

Open your browser:

`http://127.0.0.1:8000/`
